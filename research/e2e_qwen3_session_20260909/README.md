# Qwen3-VL session-bundle challenger

This is the main end-to-end challenger.  One training example is an entire HAU session,
containing all two or three videos and every question attached to them.  The model therefore
learns action-pool, temporal-order, and emotion-bijection evidence jointly rather than making
isolated row predictions.

Training randomly withholds one clip from session triples, matching the production test's
mixture of complete triples and two-clip blocks.  Validation is subject-disjoint and reports
both complete-session and deterministic 38%-pair-thinned results.

No competition submission is generated by this kernel.
